# **CLI GAME** 

**THIS IS ROGUE 1980** inspired game written for CLI.
Point of game is to defeat all Terrorists. But be aware you have limited mooves to make, then 
it's Terrorists turn. They can shoot you! If you loose all health you die!
Pick up bonus ammo and health on map and manage your limited inventory size.
Be careful when you shoot since you can only shoot in 8 directions, up, down, left, right and diagonal.

## HOW TO RUN GAME

This is CLI GAME written for .NET 8.0
To run game run main function with arg of path to root dir ConsoleGameRogue.

1. TO LAUNCH GAME, launch GAMEdRIVER.CS with argument: PathToGameRoot

2. CHOOSE AND READ CONTROLS AND RULES in MENU!

3. Enjoy!

## **Controls**  <br />
**W:** Move the cursor up. <br />
**S:** Move the cursor down.  <br />
**A:** Move the cursor left.  <br />
**D:** Move the cursor right.  <br />
**Arrow Up:** Move the player up.  <br />
**Arrow Down:** Move the player down.  <br />
**Arrow Left:** Move the player left.  <br />
**Arrow Right:** Move the player right.  <br />
**Spacebar:** Shoot. <br />
**I:** Display information about the current cell. <br />
**U:** Use an item from your inventory. <br />
**M:** Reset the current level. <br />
**R:** Reload your weapon. <br />
**P:** Pick up an item from the ground. <br />
**X:** Drop an item from your inventory. <br />
**F1:** Open the main menu. <br />
**F3:** Save your game progress. <br />
